# 注音打字小勇士 — 老師使用說明

給國小三年級電腦課用的注音輸入法練習遊戲。**純網頁、不用安裝、不連網**，學生用的是電腦上真正的「微軟注音」輸入法，練完就會用記事本打字。

## 一、怎麼開

1. 把整個 `zhuyin-trainer` 資料夾複製到學校共用資料夾或隨身碟（檔案要一起：`index.html`、`core.js`、`app.js`、`td.js`、`style.css`、`words.js`、`README.md`，還有 `tools` 資料夾）。
2. 學生電腦上**用 Edge 或 Chrome** 對 `index.html` 按兩下（或右鍵 → 開啟檔案 → Edge）。不要用 Firefox（輸入法事件不同，偵測會失準）。
3. 確認學生電腦右下角輸入法是「微軟注音」。

## 二、五個關卡在練什麼

| 關卡 | 練什麼 | 學生要做的事 |
|---|---|---|
| 第 0 關 切換中英文 | 按 **Shift** 切換中／英 | 畫面輪流叫他打英文字、打注音符號；打錯模式會跳提示 |
| 第 1 關 注音在哪裡 | 注音鍵位 | 螢幕鍵盤亮黃色的鍵，按對就過；按 Backspace 換下一題 |
| 第 2 關 聲調與送出 | 注音＋聲調鍵＋Enter | 一聲＝空白鍵、ˊ＝6、ˇ＝3、ˋ＝4、˙＝7（輕聲在注音打完後才按） |
| 第 3 關 選字高手 | ↓ 鍵＋數字選字 | 跑出同音字時，畫面會提示按 ↓ 找到正確的字再按數字 |
| 第 4 關 綜合挑戰 | 打整句、計時 | 綜合前面所有技能 |

### 挑戰模式：🏰 注音塔防

首頁最下面那張紫色卡片。怪獸一波一波從右邊走來，每隻身上寫著一個語詞，
學生打出那個語詞的注音就能消滅它；走到最左邊的城牆就扣一顆心，心扣完就結束。

幾個老師要知道的規則：

- **一次只能打最前面那隻**（有黃框與 ⬅ 箭頭），不用選目標，不會打錯對象。
- **打完注音就算消滅，不用選字、不用按 Enter**。因為選字視窗會擋住怪獸，對三年級太挫折；
  選字的練習留在第 3 關。
- 但**仍然要切到中文模式**才算數，英文模式亂按只會出現提醒，不扣分、也不會誤殺怪獸。
- **按錯一個鍵** → 錯誤 +1、連擊歸零，畫面會要求「按一下 Backspace 刪掉」；
  沒按 Backspace 之前不會繼續判定（這是故意的，讓輸入法跟遊戲保持一致）。
- 打一半想重來：按 **Esc** 或 **Enter**，這個詞會重新開始，不扣分。
- 第 10 波是**大魔王**：要**連續**打對 5 個四字語詞，中間打錯一次魔王就回一格血；
  還有個倒數，數完魔王會攻破城牆（扣 2 顆心）。打倒魔王後進入下一輪，怪獸更快。
- 當機或點到別的地方會**自動暫停**（切分頁也會），右上角也有暫停鈕。

畫面上方的「輸入法：中文／英文」燈號，是在學生按下第一個鍵後推斷出來的（網頁無法直接讀取輸入法狀態）。

## 三、示範鍵盤（老師投影用）

首頁按「示範鍵盤」。老師在輸入框打字，投影幕上會：
- 亮起老師按的鍵（同時顯示英文與注音）
- 大字顯示「正在打：ㄇㄚ」的組字過程與已送出的文字

用來示範「先按 a 再按 8 再按空白鍵」這種步驟最方便。

## 四、成績記錄（只存在那台電腦）

- 每關結束會出現「輸入座號或姓名 → 記錄成績」或「跳過」。
- 記錄存在**該台電腦的瀏覽器裡**，不會上傳。老師模式（首頁右上角 ⚙）可以查看、**匯出 CSV**（可用 Excel 開）、清空。
- 每台電腦的記錄各自獨立；若要彙整，請在每台電腦匯出 CSV 再合併。
- 老師模式也可以設定：開放哪幾關、每關題數、是否計時、是否顯示「輸入姓名」、音效開關。
- 塔防的設定也在同一頁：開放塔防、起始速度（慢／中／快）、城牆心數 1～5、
  是否出現大魔王、要不要用螢幕鍵盤提示下一個鍵（關掉難度高很多）。
- 塔防的成績會跟闖關成績存在同一張表，CSV 會多出「模式、波次、分數、最高連擊」幾欄。

## 五、修改題目（words.js）

用記事本開 `words.js`，照格式加一行即可，**存檔時編碼選 UTF-8**：

```js
{ text: "你好", zhuyin: ["ㄋㄧˇ", "ㄏㄠˇ"] },
```

- `text`：要打的字／詞／句
- `zhuyin`：每個字一格，聲調寫在最後：一聲不寫、二聲 `ˊ`、三聲 `ˇ`、四聲 `ˋ`、輕聲 `˙`
- 五個區塊：

  | 區塊 | 內容 | 用在哪裡 | 目前筆數 |
  |---|---|---|---|
  | `chars` | 單字 | 第 2 關、塔防 1～3 波 | 158 |
  | `words` | 二字詞 | 第 3 關、塔防 4～6 波 | 266 |
  | `words3` | 三字詞 | 第 3 關、塔防 7～9 波 | 77 |
  | `sentences` | 短句 | 第 4 關 | 69 |
  | `bossWords` | 四字詞 | 塔防大魔王 | 44 |

  合計 **614 筆**。語詞依主題分區（文具、教室、家裡、食物、動物、天氣、交通、身體、動作、心情、時間、禮貌、電腦課…），
  用記事本搜尋 `── 食物` 這種標題就能找到要改的地方。
- **變調一律標「本調」**：「一」一律 `ㄧ`、「不」一律 `ㄅㄨˋ`、疊字第二字用本調（媽媽＝`ㄇㄚ ㄇㄚ`）。
  理由是微軟注音用本調一定打得出那個字。真正的輕聲詞（的、了、子、們、石頭、饅頭…）才用 `˙`。
- 題庫的注音由 AI 標注並經過程式校對，**建議老師仍抽查幾題**。
- 改完題庫後，可以請 AI 執行 `node tools/check-words.js`。它會檢查注音格數、音節結構、
  「同一個國字在不同詞裡有沒有標成不同音」（最容易抓到手誤），並印出 37 個注音符號各練到幾次、
  五個聲調的分布，避免某些鍵永遠練不到。
- **刻意採用「本調」**：疊字（媽媽、爸爸、謝謝…）第二字與「一」的變調都標本調（ㄇㄚ ㄇㄚ、ㄧ ㄑㄧˇ），因為微軟注音用本調一定打得出該字；這與國語課本的輕聲／變調標法不同，老師可視需要向學生說明。

## 六、上課前 5 分鐘檢核表（請用真實微軟注音實測）

1. 開第 0 關：在英文模式打 `hi` → 燈號顯示「英文」、答對。
2. 按一下 Shift 切成中文，題目要求 ㄅ 時按 `1` → 螢幕顯示「正在打：ㄅ」、答對；按 Backspace 進下一題。
3. 開第 2 關：題目「媽」→ 依序按 `a`、`8`、`空白鍵`，看到「都對了！按 Enter 送出」→ 按 Enter 過關。
4. 開第 3 關：故意在選字時選錯的字 → 應出現「這個字不是「X」！按 ↓ …」提示；按 ↓ 再按數字選對 → Enter 過關。
5. 結算畫面：按「跳過」與「記錄成績」都正常；老師模式能看到記錄並匯出 CSV。
6. 開「🏰 注音塔防」：等第一隻怪獸出來，照畫面下方的順序把那串鍵按完 → 怪獸應該爆炸、分數增加。
7. 塔防裡故意按錯一個鍵 → 應出現「按錯了！按一下 Backspace 刪掉」，按了 Backspace 後能繼續打。

## 七、常見狀況

- **Caps Lock 亮著**：畫面會出現黃色警告，請學生按一下 Caps Lock。
- **Shift 按了沒切換**：有些電腦把切換鍵改成 Ctrl+Space，請學生試試看；或到 Windows 設定 → 時間與語言 → 輸入 → 微軟注音 → 按鍵，確認「切換中英模式」是 Shift。
- **點了畫面其他地方就打不了字**：輸入框會蓋上藍色「點一下這裡開始打字」，點一下即可。
- **沒有聲音**：老師模式可開關音效；瀏覽器需要先點過畫面才會出聲。
- **塔防打不到怪獸**：先看右上角燈號是不是「英文」。塔防規定要在中文模式下才算數。
- **遊戲畫面按 F9**（闖關模式）會跳出黑色診斷紀錄，輸入法行為怪怪的時候拍下來就能查。
- **題目會不會一直重複**：不會。出題改成「洗牌發牌」——一副牌發完才重洗，所以連玩好幾場
  才會再遇到同一題，塔防同一波也不會出現兩隻一樣的怪獸。

## 八、更新到 GitHub 後，學生看到舊版怎麼辦

`index.html` 裡每個檔案都帶了版本號，例如：

```html
<script src="app.js?v=20260923"></script>
```

**每次改完程式並上傳 GitHub，請把 `index.html` 裡所有 `?v=20260923` 改成當天日期**（例如 `?v=20261005`），
學生電腦才不會拿到快取的舊版。沒改的話，就要要求每一台電腦按 **Ctrl + F5** 強制重新整理。
